📚 How to add Base network to MetaMask — a $CLAW guide

New to Base? Here's how to get set up:

1. Open MetaMask
2. Click "Add Network" → "Add a network manually"
3. Enter:
   - Network Name: Base
   - RPC URL: https://mainnet.base.org
   - Chain ID: 8453
   - Currency: ETH
   - Explorer: https://basescan.org
4. Save and switch to Base network
5. Bridge ETH from Ethereum → Base via bridge.base.org

Once you're on Base, you're ready to trade $CLAW. 🦞🔧

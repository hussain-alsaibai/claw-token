## Post 4: Educational (6pm AST)
📚 Reading the $CLAW contract — a non-technical guide

You don't need to be a developer to verify $CLAW.

Go to BaseScan → search: 0x6ae6829d87eEaE1fFF4006E8BB310f4e92546cB1 (testnet)
Look for:
→ ✅ "Contract Verified" = source code is public
→ 📋 "Read Contract" = check current tax rates, owner address
→ 💼 "Write Contract" = (ignore unless you're the dev)

Key things to check in "Read Contract":
- `_buyTax` → current buy tax
- `_sellTax` → current sell tax
- `owner()` → is it renounced (zero address) or held?
- `isExcludedFromFee` → marketing + dev wallets excluded (normal)

Transparency starts on-chain. 🦞🔍

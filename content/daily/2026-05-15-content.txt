## Post 4: Educational (6pm AST)
📚 Slippage explained — trading $CLAW without getting wrecked

Slippage = the difference between the expected price and executed price.

On DEX trading, you must set slippage tolerance.

For tax tokens like $CLAW:
→ Slippage must be ≥ tax rate + ~1% buffer
→ Example: if total tax = 5%, set slippage to 6%

If slippage is too low → transaction fails ("insufficient output amount")
If slippage is too high → you accept more price movement

When $CLAW launches, we'll post recommended slippage settings.
No guesswork for new holders. 🦞📈
